# Security Policy

## Supported Versions

SwitchBot Controller is currently under active development.

| Version | Supported |
| ------- | --------- |
| Development / latest | :white_check_mark: |
| Older versions | :x: |

Security updates are provided for the latest development version.

## Reporting a Vulnerability

If you discover a security vulnerability in SwitchBot Controller, please report it privately.

Please use GitHub's **Private Vulnerability Reporting** feature available in the **Security** tab of this repository.

Please do not disclose security vulnerabilities through public GitHub Issues or Pull Requests.

When reporting a vulnerability, please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected version or commit, if known
- The potential impact
- Any relevant logs or screenshots, if available

Please do not include or publicly disclose any SwitchBot API tokens, API secrets, passwords, or other sensitive credentials in your report.

We will review valid vulnerability reports and, where appropriate, work on a fix and provide an update.

## Scope

This security policy applies to the SwitchBot Controller source code and the official plugin package distributed through this repository.

SwitchBot services, APIs, hardware, and other third-party services are outside the scope of this project.
